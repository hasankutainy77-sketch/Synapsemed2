# المحاكي الطبي (Arabic Medical Simulators Android App)

مشروع تطبيق أندرويد متكامل مبني باستخدام **Capacitor** يعمل **بدون إنترنت بالكامل (100% Offline)** ويعرض المحاكيات الطبية بملء الشاشة داخل التطبيق دون إظهار أي متصفح أو شريط عنوان أو أسماء ملفات.

## هيكل المشروع (`www/`)
- `index.html`: الشاشة الرئيسية باللغة العربية (RTL)، تدعم الوضع النهاري والليلي تلقائياً حسب النظام، وتضم بطاقات المحاكيات، زر التحديث الذكي (يتحول للون الأحمر عند وجود محاكيات جديدة)، وإخلاء المسؤولية التعليمي.
- `simulators.json`: ملف التعريف الوحيد الذي يقود القائمة بالكامل.
- `clinical-sim.html`: حالة سريرية (ألم بطني حاد).
- `appendectomy-sim.html`: استئصال الزائدة الدودية خطوة بخطوة (2D).
- `appendectomy-3d.html`: استئصال الزائدة الدودية ثلاثي الأبعاد (3D) مع حزمة `vendor/three.min.js` محلياً للعمل بدون إنترنت.
- `normal-delivery-sim.html`: الولادة الطبيعية المهبلية (2D).
- `pneumothorax-sim.html`: استرواح الصدر الضاغط وتفجير الصدر (2D).

## استبدال ملفات المحاكاة الخاصة بك
ضع ملفات الـ HTML الخمسة الخاصة بك داخل مجلد `www/` بنفس الأسماء، وسيقوم السكربت `scripts/bundle-offline-assets.mjs` تلقائياً بتضمين مكتبة `three.min.js` (الإصدار r128) محلياً وتعديل أي رابط CDN في `appendectomy-3d.html` ليعمل بدون إنترنت.
